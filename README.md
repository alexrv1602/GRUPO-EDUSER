# GRUPO EDUSER — Sitio Web Institucional (Guatemala)

Sitio web corporativo y profesional desarrollado para **GRUPO EDUSER** (Soluciones Corporativas Multisectoriales), basado estrictamente en su Dossier Corporativo oficial y su sede central en Mixco, Guatemala.

- **Correos Institucionales:** `proyectos@grupoeduser.com` / `licitaciones@grupoeduser.com`

## Cambios de Diseño Aplicados (Eliminación del Estilo Genérico de IA)
1. **Diseño Editorial y Arquitectónico:**
   - Se eliminaron tarjetas burbuja, sombras excesivas y degradados de neón típicos de plantillas de IA.
   - Geometría sobria con esquinas nítidas (`border-radius: 4px` / `2px`) y bordes arquitectónicos delgados de `1px`.
2. **Tipografía Corporativa Clásica:**
   - *Archivo* para encabezados con carácter institucional y peso visual.
   - *IBM Plex Sans* para textos descriptivos y lectura fluida.
   - *IBM Plex Mono* para códigos de expediente, números de teléfono y sellos institucionales.
3. **Paleta Oficial Extraída del Logo:**
   - Azul Marino Profundo (`#002B66`) y Azul Real (`#003F94`).
   - Oro Metálico Ejecutivo (`#C59B27`, `#DFB742` y `#9A7416`).
   - Fondos claros contrastados (`#FFFFFF` y pizarra arquitectónica `#F4F7FA`).

## Archivos
- `index.html`: Estructura semántica completa, metadatos y mapa satelital.
- `styles.css`: Hojas de estilo responsive y diseño institucional.
- `script.js`: Interacciones (menú móvil, modal de dossier, enlace de ejes y formulario).
- `assets/logo-cropped.png`: Logotipo oficial recortado.

## Cómo abrir
Haga doble clic sobre `index.html` en el explorador de archivos para abrirlo en su navegador preferido.
